# Package 025 — CKPool Competitive Acceptance Testing

Provides a repeatable Version 1.0 release gate for Seymour's native Bitcoin mining pipeline. It adds persisted acceptance reports, release criteria APIs, a runtime contract suite, SHA256d throughput smoke benchmarking, and regression coverage across Stratum, template generation, share validation, block assembly/submission, VarDiff, and RPC failover.

This package does not claim benchmark superiority over CKPool without running both products on identical hardware. It supplies the Seymour-side harness and records evidence so a controlled comparison can be performed honestly.
