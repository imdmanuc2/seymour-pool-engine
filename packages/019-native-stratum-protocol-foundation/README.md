# Package 019 — Native Stratum Protocol Foundation

Introduces Seymour's native Stratum V1 TCP foundation with subscribe, authorize,
configure, extranonce subscription, synthetic job notification, placeholder share
submission, PostgreSQL persistence, monitoring API routes, tests, and smoke tooling.

This rebuilt package targets the actual Seymour Pool Engine repository structure and
uses the existing `seymour_engine.schema_migrations(migration_id)` convention.
