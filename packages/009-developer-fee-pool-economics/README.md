# Package 009 — Developer Fee & Pool Economics

Adds transparent and mandatory Seymour developer-fee accounting with a hard minimum of 0.75 percent. Operators may increase the fee but cannot disable it or configure a lower value in official builds.

The package adds fee profiles, SOLO/PROP/PPLNS weighted allocation, operator fees, immutable calculation records, allocation records, hash-linked integrity metadata, public policy reporting, and economics summaries.

This package performs accounting only. Wallet custody and transaction payouts are introduced in Packages 011 and 012.
