# Package 004 — Statistics Engine

Adds rolling platform, pool, and worker statistics derived from SPE-owned share data. Supported windows are 1 minute, 5 minutes, 15 minutes, and 1 hour. It also introduces deterministic synthetic-share generation for repeatable scale and regression testing.

Run `scripts/doctor.sh`, `scripts/install.sh`, then `scripts/verify.sh` from this package directory.
