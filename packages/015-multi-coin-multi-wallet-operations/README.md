# Package 015 – Multi-Coin & Multi-Wallet Operations

Adds a coin/network registry and true many-wallet-per-coin operations: scoped assignments, selection policies, reserve protection, health and balance observations, deterministic failover selection, and ledger-vs-blockchain reconciliation.

Install from the repository root with `./packages/015-multi-coin-multi-wallet-operations/scripts/doctor.sh`, `install.sh`, then `verify.sh`.
